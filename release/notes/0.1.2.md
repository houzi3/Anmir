## Anmir 0.1.2

- 公司内网禁用 mDNS 或跨网段发现失败时，可通过 Anmir Connect 辅助系统扫码配对，无需手动填写手机 IP 和端口。
- 首次配对后保存连接信息，手机恢复 Wi-Fi 时自动回传新调试端口；支持立即重试、停止辅助连接和忘记 Mac。
- 手机辅助组件采用紧凑页面与新图标；启动成功后定位无线调试条目，系统设置使用独立任务栈。
- 包含 PR #2 的更新检查改进：投屏窗口可以检查更新，通过静态 update.json 获取版本与下载校验信息。
- 修复后台运行时点击 Dock 无窗口的问题：关闭全部窗口后隐藏 Dock 并继续重连，重新打开应用会恢复已有窗口或显示设备列表；最小化保留 Dock，⌘Q 完全退出并停止后台重连。

### 公司网络扫码

1. 下载下方 **AnmirConnect-0.1.2.apk** 并在手机安装。若安装过早期测试 APK，请先卸载测试版；正式版改用固定发布签名。
2. 在 Mac 的扫码窗口选择 **公司网络扫码一直转圈？试试这个方案**，保持二维码窗口打开。
3. 打开手机 **Anmir Connect**，点击 **启动辅助连接**，成功提示后会打开开发者选项并尝试定位无线调试。
4. 进入 **无线调试 → 使用二维码配对设备**，扫描 Mac 上的二维码；配对后自动投屏。

自动重连需要保持两端 App 和无线调试运行。系统关闭无线调试时需手动开启；Mac 地址变化时重新扫码。公司网络仍需允许设备双向互通。

## English

Company-network QR pairing now supports routed networks where mDNS discovery is blocked. Install the included Anmir Connect APK, start the helper, then scan the Mac’s company-network QR code with Android’s **Wireless debugging → Pair device with QR code** scanner. Keep both apps and wireless debugging running for reconnection after Wi-Fi returns.

The Android companion uses a fixed release signing key. Uninstall earlier preview APKs once before installing this release. This version also includes PR #2’s update discovery improvements and static update manifests.

Reopening Anmir from Finder or Spotlight restores existing windows or opens the device list. Closing every window hides its Dock icon while reconnection continues; minimized windows keep the Dock icon. Command-Q closes Anmir and its mirrors and stops background reconnection.
