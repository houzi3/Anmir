## Anmir 0.1.3

- 更新 macOS 应用图标：安卓机器人面对 Mac 屏幕中的倒影，更直观地表达 Android 与 Mac 之间的投屏。
- 投屏窗口继续保留右下角的小手机角标，方便区分设备列表与正在投屏的窗口。

## English

Anmir has a new macOS app icon: an Android robot looking at its reflection in a Mac display. Mirroring windows keep the small phone badge in the lower-right corner, so they remain easy to distinguish from the device manager.

Includes macOS 11+ installers for Apple Silicon and Intel, plus the Android 11+ Anmir Connect companion signed with the existing release key.
