- 在 Mac 的设备列表中可为安卓设备添加备注，选择 APK 安装目标时也能看到备注。
- 在 Mac 上用 Anmir 打开 APK 时，可选择多台已连接的设备，一次安装同一个 APK。
- 批量安装时，可查看每台设备的状态和结果，并单独重试安装失败的设备。
- 把 APK 拖入 Mac 上的投屏窗口，即可在当前设备上安装、查看安装进度和结果，并在失败时重试。

- Add nicknames to Android devices in the Mac device list and see them when choosing where to install an APK.
- Open an APK with Anmir on Mac to install it on multiple connected devices in one batch.
- Track the status and result for each device during a batch install and retry only the failed installs.
- Drop an APK onto a mirroring window on Mac to install it on that device, see progress and results, and retry if installation fails.
